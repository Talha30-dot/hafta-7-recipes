# Recipes Explorer

A lightweight recipe browsing project built with **HTML**, **JavaScript**, **Fetch API**, and **DaisyUI**.

The application fetches recipe data from the DummyJSON Recipes API and renders it in a responsive interface.

## Tech Stack

- HTML5
- JavaScript
- Fetch API
- DaisyUI
- DummyJSON Recipes API

## Features

- Remote recipe data fetching
- Dynamic recipe card rendering
- Responsive interface
- API-based frontend practice

## Run Locally

No build step is required.

1. Clone the repository.
2. Open `index.html` in a browser, or run it with a local development server such as VS Code Live Server.

## Purpose

This project was created to practice asynchronous JavaScript, API consumption, DOM rendering, and responsive frontend UI development.
